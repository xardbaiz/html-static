# AGENTS.md

## Проект

`html-static` — статические страницы. Здесь нет сборки и тестов; HTML открывается напрямую.

## Словарь латышского ()

- `lv-edvibe-cheatsheet.html` — страница-шпаргалка, рендерит словарь.
- `lv-data.json` — **основной** файл данных (базовая структура, все категории).
- `lv-data-1.json`, `-2`, `-3`, … — файлы-пополнения.
- `DATA_FORMAT.md` — **обязательный контракт формата. Читать до любых правок данных.**
- `lv-data.schema.json` — машинная валидация (см. ниже).

## Правила при работе с `lv-data*.json`

1. **Сначала прочитать `DATA_FORMAT.md`** и сверяться с `lv-data.schema.json`.
2. Новые слова кладутся в **новый** файл `lv-data-N.json`, где `N` — следующий
   свободный номер. Не редактировать `lv-data.json` и уже существующие файлы-пополнения,
   если пользователь явно не попросил.
3. **Непрерывная нумерация.** Пропуск номера обрывает загрузку: страница читает `-1`, `-2`, …
   до первого отсутствующего файла.
4. **Только новые слова.** Перед созданием файла проверить дубли по всем `lv-data*.json`
   (сравнивать основы слов, а не только точное совпадение — `skuķis`/`skuķa`).
5. `name` категории — **точный ключ слияния**. Использовать только имена из реестра
   в `DATA_FORMAT.md` §4. Новая категория — только для новой темы, и тогда обновить реестр.
6. Не добавлять в файл-пополнение `last_updated`/`module_info`, если пользователь не просил.

## Проверка перед ответом пользователю

```powershell
# дубликаты + нумерация + кириллица (без интернета, мгновенно)
node check-vocab.mjs

# структура по схеме (исключаем сам файл схемы)
npx.cmd --yes ajv-cli@5 validate -s lv-data.schema.json -d "lv-data.json" -d "lv-data-*.json" --strict=false
```

`node check-vocab.mjs` — **главная** проверка перед созданием нового файла: показывает,
не дублируются ли уже существующие слова. Запускается из папки `pages`.

(именно `npx.cmd`: в этой системе `npx.ps1` заблокирован ExecutionPolicy.
Не использовать маску `lv-data*.json` — она захватывает `lv-data.schema.json`.)

Все проверки должны быть зелёными (`exit 0`) — иначе не отдавать результат.

## Git-хук

`.git/hooks/pre-commit` запускает `check-vocab.mjs` при коммите файлов `lv-data*.json`
и отменяет коммит при дубликатах/битой нумерации. Переустановка после клонирования:

```powershell
node pages/check-vocab.mjs --install-hook
```
