# html-static

Статические HTML-страницы для личных виджетов Notion и небольшой шпаргалки по латышскому словарю.

Сборки нет: файлы открываются напрямую в браузере.

## Структура

| Путь | Что это |
|------|---------|
| `index.htm` | корневая страница-заглушка |
| `widgets/stock.html` | виджет котировок TradingView |
| `pages/lv-edvibe-cheatsheet.html` | шпаргалка, рендерит словарь |
| `pages/lv-data.json` | основные данные словаря (полная структура) |
| `pages/lv-data-1.json`, `-2`, … | пополнения словаря, грузятся по порядку без пропусков |
| `pages/DATA_FORMAT.md` | контракт формата данных — читать перед правкой `lv-data*.json` |
| `pages/lv-data.schema.json` | JSON-схема для валидации данных |
| `pages/AGENTS.md` | правила работы с репозиторием для агентов |

## Как открыть

Достаточно открыть нужный файл в браузере, например:

```bash
xdg-open pages/lv-edvibe-cheatsheet.html
```

Часть страниц тянет ресурсы из интернета (TradingView, шрифты), поэтому без сети они выглядят иначе.

## Проверка данных словаря

Запускается из папки `pages`:

```bash
# дубликаты, нумерация файлов, кириллица
node check-vocab.mjs

# валидация структуры по схеме
npx --yes ajv-cli@5 validate -s lv-data.schema.json -d "lv-data.json" -d "lv-data-*.json" --strict=false
```

Все проверки должны завершаться с кодом `0`.

## Git-хук

`pre-commit` прогоняет `check-vocab.mjs` при коммите `lv-data*.json`. После клонирования его нужно установить:

```bash
node pages/check-vocab.mjs --install-hook
```

## Правила пополнения словаря

- Новые слова — всегда в **новый** файл `lv-data-N.json` со следующим свободным номером.
- Нумерация файлов непрерывная: пропуск номера обрывает загрузку всех следующих файлов.
- Перед добавлением проверить дубли по всем `lv-data*.json` (по основе слова, не только по точному совпадению).
- Имена категорий — точные ключи слияния из реестра в `pages/DATA_FORMAT.md`.

Подробности — в `pages/DATA_FORMAT.md` и `pages/AGENTS.md`.
